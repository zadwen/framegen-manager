FrameGen Manager

Open FrameGen Manager from the application menu.
1. Close the game. Choose it from the Steam list, then Browse to the actual game .exe (not a launcher).
2. Choose the loader filename suggested by the compatibility guide. Pick a multiplier and click Install / update.
3. Copy the game's current Steam launch options into the app (use %command% if empty). Click Generate and copy options, and paste the result into Steam's game Properties > Launch Options.
4. Start the game, enable DLSS Frame Generation, and use Check status. Backspace opens the unlocker menu when supported.

The mod requires a compatible game; it does not add DLSS support to every game. Do not use it with anti-cheat. Some games require different loader names or additional setup. The app will not overwrite existing loader or config files, or manage existing installations it did not create (including the existing Cyberpunk installation).

Remove managed install deletes only files that match what this app installed. Remove the added launch options manually afterwards. The mod can change its config; if removal refuses, inspect and back up the files before manual removal.
